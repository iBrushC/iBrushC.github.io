Title: Deploying Code on The Fastest Supercomputer
Description: Creating in-situ logging solutions for HPC simulations 
Image: catalyst.jpeg
Tags: Internship
Date: August 2023
Content:
I was invited back for another internship at Kitware to once again work on scientific computing. On my first day, they handed me a laptop and a 250,000 line codebase and told me to "get familiar with it". My task was to work with a project called Catalyst to deploy in-situ computing for two extremely compute-intensive softwares.

<br><br>

In-situ computing in this case was basically just creating renderings on the supercomputer and sending those back while the program was running. When one single run on a top-end supercomputer takes 10 days, knowing if it messed up early on is a huge advantage. I worked with two softwares, one which computed micro-scale electromagetic simulations and the other which did industrial mixing simulations.

<br><br>

I spent the summer learning about build systems using CMAKE and some proprietary tools to merge and test Catalyst across both softwares, and got to talk to some really cool people at different labs and companies. I ended up deploying the code across the official builds of both the softwares, which was run and tested on Frontier, the (at the time) fastest supercomputer in the world.

<br><br>

Overall great experience in working with large codebases, different people, build systems, thorough testing, and documentation.
